No Bazarr module or fixture may be copied into the Go source tree. Provider documentation and independently captured responses are authoritative when they differ from Bazarr. Every adopted behavior receives an independently authored test.

## Task-indexed observations

| Area and source paths | Observed behavior | Decision and proving test |
|---|---|---|
| Sonarr/Radarr discovery: `bazarr/sonarr/`, `bazarr/radarr/`, `bazarr/app/signalr_client.py`, `bazarr/api/webhooks/sonarr.py`, `bazarr/api/webhooks/radarr.py`, `bazarr/utilities/path_mappings.py` | Arr is the media catalog; imported file metadata is hydrated from Arr rather than inferred only from disk. Webhook test events and payloads without file IDs are ignored. Bazarr path mapping performs the first configured substring replacement. | **Adopt hydration; tighten event identity and paths.** Sanitized catalog fixtures cover IDs, scene/original names, release group, quality, absolute episode, renames, upgrades, deletes, and history reconciliation. Stable event IDs make replay a no-op. Mapping tests require the longest boundary prefix, reject traversal and symlink escapes, and enforce configured media roots instead of accepting substring replacement. |
| Embedded/external inventory: `custom_libs/subliminal_patch/providers/embeddedsubtitles.py`, `bazarr/subtitles/indexer/__init__.py`, `bazarr/subtitles/indexer/series.py`, `bazarr/subtitles/indexer/movies.py`, `bazarr/subtitles/indexer/utils.py` | FFprobe-derived streams and external files are normalized into language/variant state. Embedded extraction filters codecs and distinguishes generic, hearing-impaired, and forced dispositions. | **Adopt normalization; tighten caching and ownership.** Inventory every subtitle codec, including image tracks, without extracting it. Cache embedded rows only while path, Arr file ID, byte size, and nanosecond modification time match. Always rescan exact-stem sibling `.srt`, `.ass`, `.ssa`, and `.vtt` files; never follow symlinks. A sidecar is writable only when its path and checksum match stored installation provenance. Probe-count, PGS, unknown-language, forced, SDH, symlink, and modified-file tests prove these rules. |
| Provider pool: `custom_libs/subliminal_patch/core.py`, `bazarr/subtitles/pool.py`, `bazarr/app/get_providers.py` | Providers share a common search/download boundary, enabled providers are filtered centrally, and failures are isolated. | **Adopt the boundary; tighten instance isolation.** Compile-time factories create independently credentialed named instances. Registry/coordinator tests verify strict provider YAML, language capability validation, exact-first ordering, broad fan-out, deterministic merge, failure isolation, and separate same-type accounts. |
| Languages: `custom_libs/subliminal_patch/converters/`, `bazarr/languages/` | Providers map their own identifiers to normalized language objects, including variants. | **Adopt with BCP 47.** Configuration and provider tests cover `hr`, `en`, `pt-BR`, ISO-639 aliases, Serbian scripts, forced, and HI variants. |
| Titlovi: `custom_libs/subliminal_patch/providers/titlovi.py` | Auth token is cached; search is paginated; episode zero denotes a season pack; pack members are matched by `SxxEyy`/`xxXyy`; 429 is typed. | **Tighten.** Preserve episode-zero as pack scope, reject wrong seasons and ambiguous archives, never choose the first pack member, and persist a 5-minute no-header 429 fallback. Titlovi fixtures cover every branch. |
| OpenSubtitles.com: `custom_libs/subliminal_patch/providers/opensubtitlescom.py` | API key/user-agent headers accompany login, search, and download; tokens are cached and refreshed after 401; exact hash evidence is explicit; `pt`, `zh`, and Mexican Spanish use provider-specific codes; 406 download quota and 429 rate limit are distinct; download requests return temporary URLs. Bazarr may sleep/retry inline and logs redacted request/response details. | **Adopt the HTTP contract; tighten retry, redaction, and streaming.** Use the public `/api/v1/login`, `/subtitles`, and `/download` contract with first/last 64-KiB movie hash. Refresh once immediately after 401, then persistently disable only that named account. Return 406/429 as operation-scoped typed state without sleeping. Never persist temporary URLs or include request URLs/tokens in transport errors, and stream through a configured byte ceiling. Independent tests cover hashing, ID/query priority, pagination, language round trips, token refresh, repeated rejection, quota reset, malformed JSON, and link retrieval. |
| SubDL: `custom_libs/subliminal_patch/providers/subdl.py` | Episode search can combine standard, absolute, season-only, and title fallback queries; ranges and `unpack_files` describe packs; quota payloads are typed. | **Tighten.** Deduplicate stable result IDs, require target containment, prefer an exact direct member, and otherwise use strict pack selection. Tests cover range/release fallback, direct files, daily quota, rate limit, and service busy. |
| Matching/scoring: `custom_libs/subliminal_patch/subtitle.py`, `custom_libs/subliminal_patch/score.py`, provider `get_matches` methods | Providers expose match evidence and shared code assigns signal weights. | **Tighten.** Use hard identity gates and one explainable 0–100 score across all providers. Table tests independently verify every gate, weight, and tie-break. |
| Archive/pack selection: `custom_libs/subliminal_patch/providers/utils.py` and provider-specific archive methods | Archive helpers filter extensions and select episode members by number/title; some single-file paths fall back to the first member. | **Reject arbitrary fallback.** Safe extraction rejects traversal/symlinks/limits; packs require one direct, numbered, ranged, absolute, or high-confidence title match. Hostile and ambiguous fixtures prove fail-closed behavior. |
| Adaptive search/backoff: `bazarr/subtitles/wanted/`, `bazarr/subtitles/upgrade.py` | Repeated searches are delayed and provider availability affects whether work proceeds. | **Tighten.** Persist the approved deterministic missing/failure/upgrade schedules independently of provider cooldown. Fake-clock tests verify restart behavior and no-result indexes. |
| HTTP and throttling: `custom_libs/subliminal_patch/http.py`, `custom_libs/subliminal_patch/global_rate_limiter.py`, `bazarr/app/get_providers.py`, `custom_libs/subliminal_patch/providers/utils.py` | `RateLimit`/`RateLimit-Policy` and informal `X-RateLimit-*` windows influence pacing; `Retry-After` can trigger an inline retry; mapped exceptions disable a provider for fixed intervals. | **Adopt response evidence; reject long sleeps and global account coupling.** Parse named standard windows, `X-RateLimit-*`, seconds/date `Retry-After`, and JSON reset times; the most restrictive future window wins. Persist state by provider instance and `all`/`search`/`download`/`auth` scope. Per-instance token buckets/semaphores and a shared-origin semaphore gate requests. A remote cooldown returns immediately to scheduling. Tests prove header precedence, clock-skew rejection, restart recovery, account/scope isolation, shared-origin serialization, and the approved Titlovi/OpenSubtitles/SubDL fallbacks. |
| Upgrades/install: `bazarr/subtitles/upgrade.py`, `bazarr/subtitles/download.py` | Existing scores influence upgrades and saved subtitle state is tracked. | **Tighten.** Upgrade only owned, checksum-unchanged files for exact hash or a score delta of at least 10; use same-filesystem atomic replace and rollback. Fault-injection tests cover every write boundary. |

## Refresh procedure

Before changing behavior, compare the relevant upstream file at the pinned commit and current Bazarr HEAD. Record material drift here, then validate it against the provider's current public contract. Do not silently change `subsyncd` behavior merely to match Bazarr.
